# 🎮 Game Space / 游戏集合

> **🚀 在线体验**：部署到 Cloudflare Pages 后在此填入自定义域名（如 `play.你的域名.com`）。当前 Pages 配置：生产分支 `main`，构建命令留空，输出目录 `/`。

这是一个精心打造的 **开源 HTML5 (H5) 小游戏** 合集平台，**汇聚了来自开源社区的 60 款优秀小游戏**。我们致力于整理和分享这些可以在浏览器中直接运行的精彩内容，为您提供一个便捷的试玩、娱乐与学习平台。


## ✨ 项目亮点

- **开源汇编**：本项目中的所有游戏资源均**收集自互联网开源项目及公开资源**，旨在致敬开源精神，方便开发者学习与参考。
- **丰富多样**：包含 60 款游戏，涵盖动作、益智、赛车、射击等多种题材。
- **即点即玩**：无需安装任何插件，纯现代浏览器支持。
- **响应式设计**：导航页适配桌面端与移动端设备。
- **纯静态架构**：无需后端数据库或复杂的构建流程，部署简单。

## 🕹️ 本站新增能力

- **统一游戏外壳**：`/play/<游戏目录名>/` 提供自动存档（每 30 秒）、暂停、全屏、静音、虚拟按键与结算页。
- **进度永存**：本地存档 + 登录后的云端同步；支持存档码导出/导入，换设备接着玩。
- **发现入口**：首页精选三款、场景分类（摸鱼解压/烧脑挑战/双人同屏/怀旧街机）、最近玩悬浮球、每日挑战。
- **PWA**：可添加到桌面，核心页面离线可玩。
- **会员方案**：`/pricing/` 已挂出价格与需求埋点，支付通道待接入。
- **SEO 攻略**：`/guide/` 下三款游戏提供玩法、技巧与 FAQ 结构化数据。

### 后端 API（可选）

`worker/` 目录包含 Cloudflare Worker + KV 的全部接口代码。在 CF Dashboard 创建四个 KV namespace 后，把 ID 与随机 `JWT_SECRET` 填入 `worker/wrangler.toml`，执行：

```bash
cd worker
wrangler deploy
```

再将 Worker 路由绑定到同一域名的 `/api/*`。未配置后端时，本地存档、存档码与最近玩功能仍可正常使用。

## 🚀 如何运行

由于这是一个纯静态项目，您可以通过以下几种方式运行：

### 方法 1：使用 VS Code Live Server (推荐)
1. 在 VS Code 中安装 **Live Server** 插件。
2. 右键点击 `index.html`。
3. 选择 "Open with Live Server"。

### 方法 2：使用 Python 快速启动
如果您安装了 Python，可以在终端中运行：

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```
然后访问 `http://localhost:8000`。

### 方法 3：直接打开（仅浏览导航页）
双击 `index.html` 只能看游戏列表。`/play/`、`/assets/` 使用根绝对路径并依赖 `_redirects` 路由重写，本地调试请用上面的 HTTP 服务方式；单独测试外壳可访问 `/play/index.html?g=17-吃水果的蛇`。

## 🛠️ 技术栈

- **Frontend**: HTML5, CSS3, JavaScript
- **Game Engines**: 包含 Construct 2 导出项目、jQuery 插件及原生 Canvas 实现。
- **Styling**: 导航页使用原生 CSS Flexbox/Grid 布局与渐变设计，追求极简与美观。
